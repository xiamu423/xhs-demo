美妆主题统一结构规则（2026-11-12）

一、一个主题，一套结构
所有美妆笔记使用 BeautyCard / Candidate / Fact 数据类型和同一个渲染组件。
结构顺序固定；笔记内容决定字段是否填写和展示，不创建求购型/测评型两套模板。

笔记级：
- noteId：原笔记标识，必填。
- title：作业名称，必填；作者身份可编辑。
- context：原帖背景，选填。记录作者明确说过的肤色、眼型、偏好、目标、评价范围，不从照片猜测。
- candidates：候选列表，至少一项；数量不限。单一候选和多候选使用相同数据类型。

候选级（展示顺序固定）：
- id、name：必填；名称无法确认时用原帖图序号，不从包装猜色号。
- nameRefs：命名证据；从作者回复确认系列/名称时填写。
- tag、image：可选摘要和真实配图；无图不造图，不用无关图填充。
- basis / 评价依据：明确归属谁的观点，包括正面和负面评价，不把个人意见写成普遍事实。
- usage / 怎么用：只有明确操作方法才填写。
- cautions / 选择前留意：来源明确的限制、前提或对当前需求的冲突。
- differences / 不同体验：同一候选不同人的冲突体验。保留主体和肤色等已有条件，不强行裁决。
这些内容统一为 Fact{text,refs[]}。每一条必须能返回正文、正文图或具体评论。
字段缺失或空数组时，标题、占位和空白全部隐藏；不填「暂无」凑齐结构。
需求属于 context，不能直接转成候选功能；没有直接证据不勾选「满足需求」。

交互结构统一：
- 展开候选查看字段 → 核对来源 → 保存选择。
- 收藏的是原笔记；保存选择记录 noteId + candidateId；两者独立。
- 「抄了」独立记录参考或尝试状态，可取消，不要求先收藏/保存，不代表购买或效果验证。
- 反馈关联具体笔记和候选，不要求先标记「抄了」。公开范围在提交前说明，允许撤回。
- 一条反馈在原笔记评论区保存，作业/搜索/点点只引用同一记录；撤回同步消失。

三、实现边界
这是本地前端 demo。素材快照编译进入应用，结构化卡片由可审查的数据脚本整理；没有实时模型调用、全站搜索、后端账号或向小红书发布。
反馈、收藏、选择、「抄了」保存到当前浏览器 localStorage，键为 xhs-beauty-v2。
后续接模型时，输出应通过上述统一 schema 及来源校验，不允许模型任意改模板。
数据准备：python3 scripts/prepare-beauty-data.py
来源文件位于 ../数据采集/notes/beauty_01 与 beauty_02；脚本仅读取这些原始数据。
卡片定义在脚本中，TypeScript 类型和顺序在 src/data.ts，渲染在 src/Prototype.tsx。
来源校验包含引用存在、归属一致、引用不含 AI 评论、回复根节点存在、候选 ID 唯一。
28 个受保护运行时文件未改动。正式构建使用 npm run build（含 check:runtime）。

五、AI 总结与作业入口（2026-11-12）

本节的作业内部展示已升级为下述方案 Tab 版，原来源与返回链路仍保留。
搜索折叠卡整体进入点点详情；正文不另设跳转分流。详情以用户偏好和选择建议为主，先给条件建议，再用具体笔记和评论支撑，避免逐篇转述。候选快捷入口定位统一作业中的对应项；关闭作业、查看原文后返回点点均保留阅读位置。
建议与引用在src/ai-content.ts维护，引用校验排除不存在或AI来源。当前追问通过有限规则匹配配色、闪片、花知晓和预算；不代表接入实时模型。新增回答收藏沿用本地存储。验收及截图见design-qa.md。

六、方案 Tab 版（2026-11-12）
展示顺序：标题/适用条件 → 方案Tab → 单一当前方案 → 通用提醒 → 公共讨论 → 问一问 → 最新信息（有依据才出现）。保留Candidate ID和来源，不重置原有选择。原帖背景收进可展开区域，缺失用法等字段隐藏。
额外数据位于src/task-content.ts，统一TaskExtras包含intro、tabLabels/order、notices、discussions、questions、updates。问答绑定questionRef与answerRefs；标题可归纳，详情展示真实原问题和回复，校验来源存在、同篇、非AI。
TaskUpdate需要title/text/updatedAt/refs，可带candidateId；当前两篇都没有更新，不填假参数。
Saved.questions记录noteId/candidateId/title/date，answers关联questionId与noteId，alsoAsked保存关注ID。沿用xhs-beauty-v2并补默认数组。问答属于作业内区域，不冒充原笔记新评论；使用反馈仍沿用原评论回流。撤回问题会移除其本地回答和关注。仅当前浏览器持久化，无平台发布或通知。

七、界面精简（覆盖前述独立背景和保存选择规则）
作业卡从方案Tab开始，背景仅在有价值时融入方案内容。移除顶部归属、引导、独立原帖信息、选一个方案看、通用提醒标签和回到原笔记。
取消“选这个”独立保存选择，唯一主操作为“抄了”；tried继续按noteId:candidateId记录。旧choices保留兼容，不读作默认选中、不再显示已选。默认进入最近抄过的有效方案，否则首项；AI指定方案仍优先。
反馈的skin字段兼容旧数据，但UI改为通用个人情况；新的内容仍存同一字段。反馈和问答的撤回文案统一为删除，删除逻辑继续引用同一记录。移除表单公开说明与回答placeholder，心得placeholder统一为说说抄作业的心得。
